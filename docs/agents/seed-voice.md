# Converting the Seeded Ode into the payer's voice (once, #35)

`npm run seed:voice` converts the hosted Seeded Ode's stored audio and replaces it. It spends ElevenLabs credits (a stem split and a speech-to-speech pass of about 8 s each for a 35 s song), so run it once, after the Seeded Ode is made (on the hosted site, or with `npm run seed:ode` above) and its lines are as wanted. It does not run on Render (there is no ffmpeg there): run it on the payer's own machine against the hosted database.

1. Have Node 24 and `ffmpeg` on the PATH (`ffmpeg -version`; `FFMPEG_PATH` names it otherwise).
2. In `.env`: `ELEVENLABS_API_KEY` and `ELEVENLABS_VOICE_ID` (the payer's cloned voice).
3. In `.env.seed` (gitignored, read after `.env`, so it wins): `DATABASE_URL=<ode-db's External Database URL from the Render dashboard>?sslmode=require`. The internal URL only resolves inside Render. Do not put this in `.env`, which the local server also reads.
4. `npm run seed:voice`. It prints the database host (never the keys), runs the schema migration (adds the `voice` column if the web service has not booted since), converts, and prints the original and converted length in ms. A non-zero exit means nothing was replaced.

What it refuses, with nothing replaced: no Seeded Ode yet; already converted (a second run would degrade it; to redo, build the Seeded Ode's ledger over and make it again, which also takes the label away); ElevenLabs or ffmpeg failing; the Seeded Ode being made again during the run; a converted remix whose length is more than 250 ms from the original's, and vocals whose first sound moved by more than 250 ms. That last check is how the line windows are kept valid: they were found in the original, and nothing re-finds them, so the remix must be as long. Still check by ear afterwards: click each line on the page and hear that it starts on its words. If the vocals have artifacts at the line edges, keep Eleven Music's vocals (do not run it, or make the Seeded Ode again).

Only the Seeded Ode is touched (`owner = 'seeded'`); judges' Own Odes are never converted or labelled. The page's label is "in my voice"; if the voice is not recognised in the H3 test, set `VOICE_LABEL=like` in the web service's environment (and in `.env` locally) and restart: the label reads "a voice like mine". The words live in `src/server/voice.ts` and the variable is read once at start; unset or any other value keeps "in my voice".

Before replacing anything the command also checks the remix is safe: the sung vocals' first sound (found with ffmpeg's `silencedetect` at -40 dB) is within 250 ms of the original vocals' first sound (`VocalsMoved`), because a remix can be the right length with its singing shifted and every line window would then be off; and the mix is summed then limited (`alimiter`, peak 0.9) so two loud stems cannot clip. The onset check measures the vocals stems, not the remix: the music plays from the start, so the remix's own leading silence says nothing about where the singing starts. If it refuses with `VocalsMoved`, the stems' quiet intro may have tripped the threshold (stem bleed or converted breath noise); listen to both before deciding to keep Eleven Music's vocals.
